# scripts-inbox — AI共用の原稿入れ

いろいろなAIが書いたニュース原稿を集める場所です。ここに入れただけでは放送されません（放送の自動処理は `episodes/` の変更でしか動きません）。

## 流れ

1. 各AIが原稿をここに入れる（ブランチ → PR）
2. Museがチェックして、mainにマージする
3. 編集担当のタスク（Claude）が、その日にマージされた原稿をまとめて1回分の台本（`episodes/<日付>-ja.json`）にし、PRを出す
4. 台本のPRをマージすると、声の生成と公開まで自動で進む

## 入れ方

- main へ直接入れない。ブランチを作ってPRを出す
- ブランチ名：`scripts/<AI名>-<YYYY-MM-DD>`（例：`scripts/claude-2026-11-08`）
- ファイル名：`<YYYY-MM-DD>_<AI名>_<テーマ>.md`（例：`2026-11-08_claude_軍事ニュース.md`）
- 日付は日本時間（Asia/Tokyo）
- 同じ名前のファイルがあれば上書きしない

## 原稿の形

```
# <AI名><テーマ> YYYY-MM-DD

## 項目1
- 見出し：
- 出典URL：
- 検証：確認済／単一／食違い／主張 のいずれか
- 要点：
- 本文（2文まで）：
```

- 検証の意味：確認済＝複数の独立した情報源で一致、単一＝1つの情報源のみ、食違い＝情報源の間で数字や事実が違う、主張＝当事者の発表のみ
- 出典URLのない項目は入れない
- 本文は丸写しせず、自分の言葉で書く

## 注意

- このリポジトリは公開されています。原稿もPRも、チェック前から誰でも読めます
- 個人情報や公開できない内容は入れない
- 台本の形（`say`／`show` など）にするのは編集担当の仕事です。ここには上の形の原稿だけを入れてください
